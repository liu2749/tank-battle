# 坦克大战 · Battle City

一个纯 HTML/CSS/JavaScript 实现的经典坦克大战（Battle City）复刻，单文件即可运行，无需任何依赖或构建工具。

## 玩法

- 控制你的坦克，**保卫基地**（屏幕下方中央的金色鹰徽）
- 消灭关卡内所有敌方坦克即可过关
- 基地被摧毁、或生命耗尽则游戏结束

## 操作

| 按键 | 功能 |
| ---- | ---- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| 空格 / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始当前关卡 |
| `Enter` | 开始 / 下一关 / 重新开始 |

## 游戏元素

- 🧱 **砖墙** —— 可被子弹摧毁
- ⬜ **钢墙** —— 坚不可摧
- 🌊 **水** —— 阻挡坦克，子弹可飞过
- 🌿 **草丛** —— 坦克可穿过，且会被遮挡
- 🦅 **基地（鹰徽）** —— 被击中即失败

## 运行方式

直接用浏览器打开 `index.html` 即可，或部署到任意静态托管（如 GitHub Pages）。

### 在线试玩

启用 GitHub Pages 后，访问 `https://<用户名>.github.io/tank-battle/`。

## 技术要点

- 13×13 网格地图，Canvas 3 倍像素渲染
- 平滑移动 + 半格对齐转向（经典手感）
- 简单 Web Audio 音效合成，无外部资源
- 3 个内置关卡，可自行在 `LEVELS` 数组中扩展
